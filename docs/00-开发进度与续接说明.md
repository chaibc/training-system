## 三、本地启动方式

### 后端（开发模式，H2 文件库）
```bash
cd server
mvn -q -DskipTests package
java -jar target/hanmo-server.jar --spring.profiles.active=dev
```
- 首次使用先初始化数据库：`scripts\h2-db.bat`（建表 + 演示数据）；重建用 `scripts\h2-db.bat -Reset`
- 数据文件：`server/data/hanmo.mv.db`（重启不丢；`application-dev.yml` 已设 `AUTO_SERVER=TRUE`，后端运行时也可同时连）
- 地址：`http://localhost:8080`
- 健康检查：`http://localhost:8080/actuator/health`
- Swagger：`http://localhost:8080/swagger-ui.html`
- H2 控制台：`http://localhost:8080/h2-console`

#### DBeaver 连接（MySQL，推荐）
| 项 | 值 |
|---|---|
| 驱动 | MySQL |
| 主机 / 端口 | `127.0.0.1` / `3307` |
| 数据库 | `hanmo_calligraphy` |
| 用户名 / 密码 | `hanmo` / `Hanmo@2026` |

- 该实例独立于机器上另一个 MySQL（3306 / 库 `backend_demo`，与本项目无关）。
- 启停：`scripts\mysql-hanmo-start.bat`、`scripts\mysql-hanmo-stop.bat`；数据目录 `D:\devtools\mysql-hanmo\data`。
- 后端连 MySQL 启动：`java -jar target/hanmo-server.jar --spring.profiles.active=local`。
- 若报 `Public Key Retrieval is not allowed`：驱动属性加 `allowPublicKeyRetrieval=true`。

> H2 文件库（`dev` profile）也能用 DBeaver 连，但 H2 2.2.224 与 DBeaver 的 `AUTO_SERVER` 探测存在兼容问题（会报 `Access to the class org.h2.server.TcpServer is denied [90134-224]`），排查成本高；需要图形化查看/改数据时统一用上面的 MySQL。
