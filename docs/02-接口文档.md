# 翰墨学堂 · 接口文档

> 适用版本：后端 `hanmo-server`（Spring Boot 3.3.5）
> 在线 Swagger（仅开发环境）：`http://localhost:8080/swagger-ui.html`
> 生产环境默认关闭 Swagger；如需临时开启，设置环境变量 `SPRINGDOC_API_DOCS_ENABLED=true`、`SPRINGDOC_SWAGGER_UI_ENABLED=true` 后重启服务。

## 一、通用约定

### 1.1 地址与环境

| 环境 | API 地址 | 管理端地址 |
|------|----------|------------|
| 本地开发 | `http://localhost:8080/api` | `http://localhost:5173` |
| 生产 | `https://你的域名/api` | `https://你的域名` |

小程序开发时 `miniprogram/config.js` 的 `development.baseUrl` 指向本机；上线时改为 `production` 并替换为备案域名。

### 1.2 认证方式

除公开接口和登录接口外，所有请求需要携带 JWT：

```http
Authorization: Bearer eyJhbGciOiJIUzM4NCJ9...
```

Token 默认 8 小时有效（`app.jwt.expire-hours`）。退出登录由客户端删除 Token 即可，服务端无状态。

权限矩阵：

| 路径 | 允许身份 |
|------|----------|
| `/api/public/**` | 无需登录 |
| `/api/auth/login`、`/api/auth/wx-login` | 无需登录 |
| `/api/mini/parent/**` | 仅家长 `PARENT` |
| `/api/mini/teacher/**` | 仅教师 `TEACHER` |
| `/api/admin/**` | 管理者 `ADMIN`、教务 `ACADEMIC` |
| `/api/admin/users/**` | 仅管理者 `ADMIN` |
| 课程、课程价格、大纲、基础字典、机构内容、规则、师资的 POST/PUT/DELETE | 仅管理者 `ADMIN`；教务只读 |
| `/api/upload` | 登录用户（管理者/教务/教师/家长） |

### 1.3 统一响应结构

成功：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

失败：

```json
{
  "code": 400,
  "message": "请输入正确的手机号",
  "data": null
}
```

| HTTP 状态 | 业务 code | 含义 |
|-----------|-----------|------|
| 200 | 0 | 成功 |
| 400 | 400 | 参数校验失败 / 业务规则不允许 |
| 401 | 401 | 未登录或 Token 失效 |
| 403 | 403 | 身份无权限 / 不属于当前账号的数据 |
| 404 | 404 | 资源不存在 |
| 409 | 409 | 冲突（如微信已绑定其他账号） |
| 423 | 423 | 账号锁定（后台连续输错 5 次密码，锁定 5 分钟） |
| 500 | 500 | 服务器内部错误，详情查看日志 |

### 1.4 分页

通用分页响应：

```json
{
  "records": [],
  "total": 86,
  "page": 1,
  "size": 10
}
```

通用分页请求参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `current` | long | 页码，从 1 开始，默认 1 |
| `size` | long | 每页条数，默认 10，最大 200（部分接口最大 500） |
| `keyword` | string | 关键字，按各模块配置的字段模糊查询 |

### 1.5 时间与金额

- 日期：`YYYY-MM-DD`，时间：`HH:mm:ss`，日期时间：`YYYY-MM-DD HH:mm:ss`。
- 金额：JSON 数字或字符串均可，后端使用 `BigDecimal` 接收；前端展示建议保留 2 位。
- 课时：`DECIMAL(8,1)`，例如 `18.0`。

### 1.6 代码中的枚举

| 枚举 | 取值 |
|------|------|
| 身份 | `ADMIN` / `ACADEMIC` / `TEACHER` / `PARENT` |
| 学员状态 | `ACTIVE` / `PAUSED` / `GRADUATED` / `LEFT` |
| 绑定状态 | `PENDING` / `ACTIVE` / `REJECTED` / `REVOKED` |
| 课程状态 | `ON` / `OFF` |
| 班级状态 | `ACTIVE` / `FULL` / `FINISHED` |
| 课次状态 | `SCHEDULED` / `DONE` / `CANCELLED` |
| 出勤 | `PRESENT` / `LEAVE` / `ABSENT` |
| 请假 | `PENDING` / `APPROVED` / `REJECTED` / `CANCELLED` |
| 补课 | `NONE` / `PENDING` / `ARRANGED` |
| 报名 | `PENDING_CONFIRM` / `PENDING_PAYMENT` / `ENROLLED` / `CANCELLED` |
| 试听 | `NEW` / `CONTACTED` / `VISITED` / `CONVERTED` / `CANCELLED` |
| 缴费类型 | `NEW` / `RENEW` / `MAKEUP` |
| 课时流水 | `PURCHASE` / `CONSUME` / `CORRECT` |
| 作品 | `PENDING` / `DISPLAYED` / `HIDDEN` / `REJECTED` |
| 评论 | `PENDING` / `APPROVED` / `HIDDEN` / `REJECTED` |
| 授权 | `ACTIVE` / `REVOKED` |
| 公告 | `DRAFT` / `PUBLISHED` / `HIDDEN` |

## 二、认证接口

### 2.1 后台账号登录

`POST /api/auth/login`

请求：

```json
{
  "username": "admin",
  "password": "Admin@123456"
}
```

响应 `data`：

```json
{
  "token": "eyJhbGciOiJIUzM4NCJ9...",
  "userId": 1,
  "username": "admin",
  "name": "机构管理者",
  "userType": "ADMIN",
  "roleCode": "ADMIN",
  "roleName": "管理者",
  "dataScope": "ALL",
  "forceChangePassword": false,
  "permissions": [
    { "moduleKey": "dashboard", "canView": true, "canCreate": true, "canEdit": true, "canDelete": true, "canSpecial": true }
  ]
}
```

说明：

- 只有 `ADMIN` / `ACADEMIC` 后台账号可用此接口；教师/家长返回 403。
- 连续输错 5 次锁定 5 分钟，返回 HTTP 423。
- 登录成功会清空失败次数，并写入登录审计。
- `permissions` 为管理端左侧导航和按钮权限来源。

### 2.2 小程序微信登录

`POST /api/auth/wx-login`

请求字段：

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `code` | 是 | `wx.login` 获取的临时 code；开发模式可用 `seed_parent_wang` / `seed_teacher_wang` 直接登录演示数据 |
| `phone` | 否 | 教师登录时传入；家长首次登录可为空 |
| `name` | 否 | 家长首次自动创建账号时的称呼，默认“微信用户” |

逻辑：

1. `code` 换 openid；开发模式 `WX_DEV_MODE=true` 时：`seed_*` 直接作为 openid，其他 code 自动加 `dev_` 前缀。
2. 若传 `phone` 且匹配到启用状态教师 → 绑定 openid 并登录教师端。
3. 已存在 openid → 返回对应家长/教师账号；后台账号禁止小程序登录。
4. 未匹配 openid 且未传 `phone` → 自动创建家长账号和 `parent_profile`。
5. 未匹配 openid 且传了 `phone` → 返回 404，提示联系教务核对教师手机号，不自动创建家长账号。

响应结构同后台登录，`roleCode` 为 `PARENT` 或 `TEACHER`。

### 2.3 当前登录用户

`GET /api/auth/me`

响应同登录响应（不含新 token）。

### 2.4 修改密码

`POST /api/auth/change-password`

```json
{ "oldPassword": "Admin@123456", "newPassword": "NewPass@2026" }
```

新密码长度 8–32。教师/家长没有密码，不支持该接口。

### 2.5 退出登录

`POST /api/auth/logout`

仅返回成功；客户端清除 Token 与用户缓存。

## 三、小程序公开接口

### 3.1 首页聚合

`GET /api/public/home`

返回 `data`：

```json
{
  "institution": {
    "name": "翰墨学堂书法培训中心",
    "brand": "翰墨学堂",
    "slogan": "一笔一画，写好中国字",
    "heroIntro": "...",
    "intro": "...",
    "phone": "0755-8888-6666",
    "wechat": "hanmo-edu",
    "hours": "周二至周日 9:00–19:00",
    "address": "...",
    "longitude": 114.0579,
    "latitude": 22.5431,
    "traffic": "...",
    "sinceYear": 2014,
    "images": [{ "id": 1, "imageUrl": "/uploads/demo/classroom.jpg", "title": "书法教室", "sort": 1 }]
  },
  "courses": [],
  "teachers": [],
  "works": [],
  "notices": [],
  "qualifications": []
}
```

`courses` 为首页推荐（featured=1、上架）最多 3 门；`teachers` 最多 4 位；`works` 为已展示作品；`notices` 最多 2 条；`qualifications` 为已核验且展示的资质。

### 3.2 筛选字典

`GET /api/public/meta`

返回 `categories`（课程分类）、`stages`（阶段）、`trialSlots`（试听时段）、`leaveReasons`（请假原因），均为启用状态且按 sort 排序。

### 3.3 课程列表

`GET /api/public/courses?categoryId=3&stageId=1&keyword=硬笔`

参数均可选。返回上架课程数组；每项包含分类名、阶段名、适龄、课时、频率、封面字色、标签、最低价格与计价说明。

### 3.4 课程详情

`GET /api/public/courses/{id}`

返回课程字段 + `prices` + `outlines`：

```json
{
  "id": 1,
  "name": "幼小衔接硬笔启蒙班",
  "price": 2880,
  "priceNote": "24 课时",
  "prices": [{ "id": 1, "classTypeId": 2, "lessons": 24, "price": 2880.00, "unit": "TERM" }],
  "outlines": [{ "title": "握笔坐姿", "lessonRange": "第 1–3 课时", "description": "..." }]
}
```

课程不存在或下架返回 404。

### 3.5 师资列表 / 详情

- `GET /api/public/teachers`
- `GET /api/public/teachers/{id}`，额外返回该教师所带班级对应的 `courses` 数组。

### 3.6 作品墙

`GET /api/public/works?type=HARD|SOFT&keyword=&month=yyyy-MM`

仅返回 `DISPLAYED` 作品，按 id 倒序。每项含学员名、班级、教师、标题、书体、内容字、图片、教师点评、点赞数。

`month` 可选，格式 `yyyy-MM`，按作品 `created_at` 过滤到该自然月；格式非法返回 400。

`GET /api/public/works/{id}` 返回作品 + 已审核通过的 `comments`。

`POST /api/public/works/{id}/like` 点赞数 +1，返回最新 `likeCount`。本期不做防重复点赞，前端做本地节流。

### 3.7 公告

`GET /api/public/notices`，返回 `PUBLISHED` 公告，按发布日期倒序。

### 3.8 试听预约

`POST /api/public/trial`

```json
{
  "studentName": "林小满",
  "age": "6 岁",
  "parentName": "林女士",
  "phone": "13800007720",
  "courseId": 1,
  "slotId": 1,
  "note": "希望周六上午"
}
```

响应：

```json
{
  "bookingNo": "ST202610300001",
  "studentName": "林小满",
  "courseName": "幼小衔接硬笔启蒙班",
  "slotName": "周六上午 09:00–10:00"
}
```

手机号必须为 11 位；预约状态为 `NEW`，教务在后台跟进。

## 四、家长端接口

> 前缀 `/api/mini/parent`，需要家长 Token。
> 所有 `studentId` 均会校验当前家长与学员的绑定关系（`parent_student.status=ACTIVE`），越权返回 403。

### 4.1 工作台聚合

`GET /overview`

返回 `parentName`、`children`、`notices`、`pendingBindings`、`pendingLeaves`。`children` 每项包含学员信息、班级、剩余课时、待审批请假、报名数、出勤数。

### 4.2 子女列表 / 档案

- `GET /children`：返回已绑定 ACTIVE 学员列表。
- `GET /children/{studentId}`：档案详情，额外返回 `classes`、`hourAccount`、`recentAttendance`。
- `PUT /children/{studentId}`：修改性别、出生日期、学校、年级。姓名、学号等关键信息需联系教务。

请求：

```json
{ "gender": "男", "birthDate": "2017-05-12", "school": "实验小学", "grade": "三年级" }
```

### 4.3 绑定关系

- `GET /bindings`：返回当前家长全部绑定（含待审核、已驳回、已解绑）。
- `POST /bindings`：提交绑定申请。
- `POST /bindings/{id}/unbind`：提交解绑申请（进入教务审核，不立即解除）。

绑定已有学员：

```json
{
  "studentNo": "HX20240018",
  "phoneTail": "2648",
  "relation": "MOTHER"
}
```

新建学员并绑定：

```json
{
  "newStudent": true,
  "studentName": "王小墨",
  "gender": "男",
  "birthDate": "2017-05-12",
  "school": "实验小学",
  "grade": "三年级",
  "relation": "MOTHER"
}
```

规则：

- 一个学员最多 2 位 ACTIVE 监护人，第一位自动为主联系人。
- 绑定已有学员需同时校验学员编号与主监护人手机号后四位。
- 绑定申请状态为 PENDING，由管理者在后台审核。
- 解绑申请把 source 置为 UNBIND，绑定保持 ACTIVE，家长审核期间仍可查看学员；教务同意后 REVOKED，驳回后恢复为普通绑定。后台待审核列表同时查询 PENDING 新绑定与 ACTIVE + source=UNBIND 的解绑申请。

### 4.4 课表与课次

`GET /schedule?studentId=1&week=2026-10-26`

`week` 为该周任意日期；返回：

```json
{
  "child": {},
  "hours": {},
  "weekStart": "2026-10-26",
  "weekEnd": "2026-11-01",
  "lessons": [
    {
      "id": 2,
      "className": "幼小衔接硬笔A班",
      "lessonDate": "2026-10-31",
      "startTime": "09:00:00",
      "endTime": "10:00:00",
      "status": "SCHEDULED",
      "statusText": "待上课",
      "attendanceStatus": null,
      "leaveStatus": null
    }
  ]
}
```

`GET /lessons/{lessonId}?studentId=1` 返回课次详情、出勤、请假、`canLeave` 与 `leaveHint`。

### 4.5 请假

- `GET /leave-options?studentId=1`：可请假课次、原因字典、截止小时数、规则文案。
- `POST /leaves`：提交请假。
- `GET /leave-records?studentId=1&status=PENDING`：请假记录，status 可选。
- `POST /leaves/{id}/makeup`：请假通过后申请补课。

提交：

```json
{
  "studentId": 1,
  "lessonId": 2,
  "reasonId": 1,
  "reasonText": "孩子发烧，需要休息"
}
```

响应：

```json
{
  "id": 4,
  "leaveNo": "QJ202610300001",
  "status": "PENDING",
  "statusText": "待审批",
  "deductHours": 0,
  "deductText": "不扣课时",
  "lesson": {}
}
```

规则：

- 只能对尚未开始、未取消、未请假的课次提交。
- 课前 ≥ 4 小时不扣课；不足 4 小时按扣 1 课时处理（`business_rule.leave_cutoff_hours`）。
- 同一课次只能有一条 PENDING/APPROVED 请假。
- 课次开始后不能请假。
- 审批结果不主动推送，家长需在请假记录查看。

### 4.6 报名

- `GET /enroll/options?studentId=1`：可选课程与班级（含已报名人数、剩余名额、价格）。
- `POST /enrollments`：提交报名。
- `GET /enrollments?studentId=1`：报名记录。
- `POST /enrollments/{id}/cancel`：取消 PENDING_CONFIRM / PENDING_PAYMENT 状态的报名。

提交：

```json
{ "studentId": 1, "courseId": 1, "classId": 1 }
```

响应含 `enrollmentNo`、`status=PENDING_CONFIRM`、应缴金额。班级满员、课程下架、重复报名会返回 400。

### 4.7 课时账户

`GET /hours?studentId=1`

返回 `account`（总/已消/剩余/有效期/续费预警）和 `ledger`（充值、消课、修正流水）。

### 4.8 上课记录

`GET /attendance?studentId=1&status=PRESENT`

返回 `records`，每项含课次、日期、教师、教室、出勤状态、消课课时。

### 4.9 成长相册

`GET /growth?studentId=1`

仅返回该学员已获授权且状态为 `DISPLAYED` 的作品，按月分组，附作品与教师点评。

### 4.10 账号与留言

- `GET /account`：账号、微信绑定状态、身份、绑定关系、子女列表。
- `POST /works/{workId}/comments`：提交作品留言。

```json
{ "content": "写得真好，能看出孩子的进步！" }
```

留言进入 PENDING，教务审核后展示。

## 五、教师端接口

> 前缀 `/api/mini/teacher`，需要教师 Token；只能操作自己档案与所带班级的数据。

### 5.1 工作台

`GET /overview`

返回 `teacher`、`today`、`todayLessons`、`weekLessons`、`classCount`、`studentCount`、`pendingLeaves`、`pendingWorks`。

### 5.2 课程与点名

- `GET /lessons?date=2026-10-31`：某日课程。
- `GET /lesson-week?week=2026-10-26`：本周课程。
- `GET /lessons/{id}`：课次详情与点名名单（学生、出勤状态、待审批请假）。
- `POST /lessons/{id}/rollcall`：提交点名。

```json
{
  "items": [
    { "studentId": 2, "status": "PRESENT", "note": "出勤" },
    { "studentId": 4, "status": "LEAVE", "note": "请假" },
    { "studentId": 6, "status": "ABSENT", "note": "缺勤" }
  ]
}
```

规则：

- 出勤、缺勤各消 1 课时；请假按已通过请假的 `deductHours` 处理；未审批请假按扣课。
- 消课幂等：重复提交只按新旧 `consumedHours` 差额调整，不重复扣课。
- 课次标记 DONE。
- 修正记录写入 `hour_ledger`，操作人留痕。

### 5.3 请假审批

- `GET /leaves/pending`
- `GET /leaves/history?status=APPROVED`
- `POST /leaves/{id}/approve`

通过：

```json
{ "approve": true }
```

驳回：

```json
{ "approve": false, "rejectReason": "课次已开始，按未到课处理" }
```

审批通过会同步写 attendance（LEAVE）与课时差额；驳回必须填写原因。

### 5.4 作品

- `GET /work-options`：可上传学员（含家长授权状态）与书体选项。
- `GET /works`：我上传的作品及审核状态。
- `POST /works`：上传作品，提交审核。

```json
{
  "studentId": 2,
  "classId": 1,
  "title": "《永字八法》",
  "workType": "HARD",
  "contentChar": "永",
  "imageUrl": "/uploads/2026/10/xxxx.jpg",
  "comment": "结体端正，笔画起收清晰。",
  "authorized": true
}
```

必须已存在 ACTIVE 的 `work_auth`，否则返回 400；作品状态 PENDING。

### 5.5 教师账号信息

`GET /account`：教师档案、身份、带班数、学员数、班级列表。

## 六、管理端接口

### 6.1 通用 CRUD

多数基础数据与简单实体提供统一 CRUD：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `{resource}/page?current=1&size=10&keyword=` | 分页 |
| GET | `{resource}/list` | 不分页列表 |
| GET | `{resource}/{id}` | 详情 |
| POST | `{resource}` | 新增（JSON 实体） |
| PUT | `{resource}/{id}` | 修改（JSON 实体，必须带 id） |
| DELETE | `{resource}/{id}` | 删除（逻辑删除视实体而定） |

资源清单：

| 资源路径 | 对应实体 / 用途 |
|----------|-----------------|
| `/api/admin/categories` | 课程分类 |
| `/api/admin/stages` | 课程阶段 |

后台新建报名：

```json
{
  "studentId": 1,
  "courseId": 1,
  "classId": 1,
  "amount": 2880,

}
```

### 6.6 班级、课次、点名、请假

班级通用 CRUD：`/api/admin/classes`。分页 `GET /api/admin/classes/page` 的每条记录额外返回 `studentCount`（在读学员数，只统计 `class_student.status=ACTIVE`），前端无需逐班查询。

班级学员：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/classes/{classId}/students` | 名单、容量、剩余名额 |
| POST | `/api/admin/classes/{classId}/students` | 添加学员 `{ "studentId": 1 }` |
| DELETE | `/api/admin/classes/{classId}/students/{linkId}` | 移出班级 |

课次（定制，自动冲突校验）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/lessons/page`、`/list`、`/{id}` | 查询；`/page` 支持可选 `dateFrom`/`dateTo`（yyyy-MM-dd，含端点），周课表按周取数 |
| POST | `/api/admin/lessons` | 新建课次 |
| PUT | `/api/admin/lessons/{id}` | 编辑课次 |
| DELETE | `/api/admin/lessons/{id}` | 删除 |

课次请求：

```json
{
  "classId": 1,
  "lessonNo": 14,
  "lessonDate": "2026-11-07",
  "startTime": "09:00:00",
  "endTime": "10:00:00",
  "teacherId": 1,
  "classroomId": 1,
  "status": "SCHEDULED",
  "originalLessonId": null,
  "note": ""
}
```

校验：班级存在、结束时间晚于开始时间、课次序号不重复、教师/教室/班级学员时间冲突。

点名与请假联动：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/workflow/lessons?date=&status=` | 点名用课次列表（含已点名人数） |
| GET | `/api/admin/workflow/lessons/{id}/roster` | 点名名单与统计 |
| POST | `/api/admin/workflow/lessons/{id}/rollcall` | 教务点名并消课 |
| POST | `/api/admin/workflow/leaves/{id}/approve` | 教务审批请假 |
| POST | `/api/admin/workflow/leaves/{id}/makeup` | 为已通过请假安排补课 |

点名请求同教师端 `{ "items": [...] }`；审批请求：

```json
{ "approve": true }
```

```json
{ "approve": false, "rejectReason": "未在截止时间前提交" }
```

安排补课：

```json
{ "lessonId": 4, "note": "安排在周六同班补课，不重复计费" }
```

安排成功后 `leave_request.makeup_status=ARRANGED`，并写 `makeup_arrangement`。同一请假不能重复安排。

### 6.7 作品、授权、评论

- 作品通用 CRUD：`/api/admin/works`（page/list/get/update/delete）。
- 教务上传：`POST /api/admin/works/upload`

```json
{
  "studentId": 2,
  "classId": 1,
  "title": "《永字八法》",
  "workType": "HARD",
  "contentChar": "永",
  "imageUrl": "/uploads/2026/10/xxxx.jpg",
  "comment": "结体端正。",
  "authorized": true
}
```

必须存在 ACTIVE 家长授权，作品状态 PENDING。

- 补录授权：`POST /api/admin/work-auths/record`

```json
{
  "studentId": 4,
  "parentUserId": 9,
  "scope": "作品展示",
  "method": "PAPER",
  "authorizedAt": "2026-10-30",
  "evidenceUrl": "PAPER-001"
}
```

- 作品审核/上下架：`POST /api/admin/works/{id}/review`

```json
{ "status": "DISPLAYED" }
```

`status` 可为 `DISPLAYED` / `HIDDEN` / `REJECTED`；展示时后端再次校验 ACTIVE 家长授权。

- 撤回授权：`POST /api/admin/work-auths/{id}/revoke`。撤回后若该学员**仍有其他有效授权**，作品保持展示；只有撤回最后一份授权时，该学员已展示作品才批量改为 HIDDEN。撤回动作会写审计日志。
- 评论审核：`PUT /api/admin/work-comments/{id}` 修改 `status` 为 APPROVED / HIDDEN / REJECTED。

### 6.10 文件上传

`POST /api/upload`，`multipart/form-data`：

| 字段 | 说明 |
|------|------|

## 七、cURL 示例

后台登录并访问看板：

```bash
TOKEN=$(curl -s -X POST https://你的域名/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"Admin@123456"}' \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")

curl -s https://你的域名/api/admin/dashboard \
  -H "Authorization: Bearer $TOKEN"
```

小程序家长登录（开发模式）：

```bash
curl -s -X POST http://localhost:8080/api/auth/wx-login \
  -H 'Content-Type: application/json' \
  -d '{"code":"seed_parent_wang"}'
```

家长课表：

```bash
curl -s 'http://localhost:8080/api/mini/parent/schedule?studentId=1&week=2026-10-26' \
  -H "Authorization: Bearer $PARENT_TOKEN"
```

教师点名：

```bash
curl -s -X POST http://localhost:8080/api/mini/teacher/lessons/2/rollcall \
  -H "Authorization: Bearer $TEACHER_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"items":[{"studentId":2,"status":"PRESENT"},{"studentId":4,"status":"LEAVE"},{"studentId":6,"status":"ABSENT"}]}'
```

上传图片：

```bash
curl -s -X POST https://你的域名/api/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@work.jpg" \
  -F "bizType=work"
```
