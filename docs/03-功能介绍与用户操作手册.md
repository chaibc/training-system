# 翰墨学堂 · 功能介绍与用户操作手册

> 适用对象：机构管理者、教务、教师、家长
> 系统范围：管理后台 + 微信小程序（家长端 / 教师端）
> 当前版本不含：校区切换、招生活动、线上支付、短信验证码、微信模板消息推送、批量导入

---

## 一、角色与账号

### 1.1 四种角色

| 角色 | 登录入口 | 能做什么 | 不能做什么 |
|------|----------|----------|------------|
| 管理者 ADMIN | 管理后台 | 全部业务、用户与权限、机构内容、业务规则 | 账号唯一，不能新增/停用管理者 |
| 教务 ACADEMIC | 管理后台 | 学员、报名、缴费、排课、点名、请假、作品、机构内容 | 不能进入用户与权限；课程只读；不能看基础数据/规则/机构内容 |
| 教师 TEACHER | 微信小程序 | 查看自己所带班级、点名消课、请假审批、上传作品 | 不能进入管理后台；不能看其他教师班级 |
| 家长 PARENT | 微信小程序 | 浏览公开内容、绑定子女、课表、请假、报名、课时、作品 | 不能发起教师身份申请；不能切换教师身份 |

### 1.2 账号规则

- **一个账号只有一种身份**，教师与家长不能在同一账号切换。
- 同一个人既是教师又是家长，请使用另一个微信号分别登录。
- **管理者账号唯一**，不可新增、不可停用，角色权限不可削减。
- 教师账号由后台创建，小程序不提供申请入口；教师登录时用微信 code + 手机号匹配。教师首次登录会把当前微信绑定到该教师账号，创建后请尽快让教师本人登录；发现绑定错误可在后台解绑微信。
- 家长首次微信登录自动创建家长账号；教师手机号未匹配时不会自动创建家长账号。
- 后台账号只允许 ADMIN / ACADEMIC 登录；小程序账号不能进入后台。
- 后台账号连续输错 5 次密码锁定 5 分钟。
- 一个学员最多 2 位有效监护人，其中 1 位主联系人。
- 家长绑定/解绑均需教务审核。

## 二、首次使用建议顺序

1. 管理者登录后台（首次登录会被强制要求修改密码）。
2. 进入「用户与权限」→ 新建教务账号（如需）。
3. 进入「机构内容」→ 机构资料，填写真实名称、电话、地址、营业时间、地图坐标。
4. 上传教学环境图片。
5. 进入「基础数据」核对课程分类、阶段、班型、教室、请假原因、缴费方式、试听时段。
6. 进入「课程与定价」创建课程、价格、内容大纲。
7. 进入「机构内容 → 师资团队」创建教师账号（手机号必填）。
8. 进入「班级与排课」创建班级，加入学员，排课次。
9. 家长微信登录 → 绑定学员 → 教务审核。
10. 开始试听、报名、缴费、点名与请假流程。

## 三、管理后台操作

访问地址：`https://你的域名/`。左侧菜单按角色权限显示。

### 3.1 登录与安全

1. 输入用户名、密码。
2. 连续输错 5 次锁定 5 分钟，页面会提示剩余时间。
3. 登录后右上角显示当前账号与角色。
4. 退出登录在左下角头像旁。
5. 修改密码：左下角头像旁的钥匙图标 → 输入原密码、新密码（8–32 位）并确认。
6. 若账号密码被重置（`force_change_password=1`），登录后会自动跳到改密页，不修改无法进入任何业务页面。

### 3.2 数据看板

展示：

- 在读学员、教师数量
- 本月消课课时
- 本月实收（线下登记）
- 待确认报名
- 今日课程
- 近 6 个月消课趋势
- 最近报名

用途：每天上班先看「待确认报名」和「今日课程」。

### 3.3 学员管理

#### 新建学员

「学员管理」→「新建学员档案」，填写姓名、性别、出生日期、学校、年级、备注。系统自动生成学员编号 `HX年份+4位`。

#### 查看档案

点击列表中的「档案」，右侧抽屉展示：

- 基本信息
- 关联家长（最多 2 位，标出主联系人）
- 班级与教师
- 课时账户：总课时、已消、剩余、有效期
- 课时流水
- 上课记录

#### 调整课时

在档案或列表操作中点击「调整课时」：

- 类型：修正 / 充值 / 消课
- 课时：正数增加，负数扣减
- 原因：必填

每次调整都会写 `hour_ledger`，不能直接改余额。

#### 家长绑定

家长端的绑定申请在「用户与权限 → 家长绑定」审核。管理者也可直接新增绑定或解绑。

### 3.4 报名与缴费

#### 前台新建报名

「报名与缴费 → 新建报名」，选择学员、课程、班级，填写应缴金额与备注。创建后状态为「待确认」，后续同样走确认、缴费流程，适合到店/电话报名。

#### 家长提交报名后

1. 「报名与缴费 → 报名申请」查看待确认。
2. 点击「确认」，可调整班级与应缴金额。
3. 状态变为「待缴费」。
4. 家长到店缴费后，点击「登记缴费」，选择缴费方式、金额、备注。
5. 系统自动：
   - 写缴费记录
   - 报名状态改为「已入班」
   - 按课程课时充值到学员账户
   - 写课时流水
   - 加入所选班级

> 本期不支持线上支付。缴费必须真实到账后再登记。

#### 取消报名

未入班报名可取消；已入班不能取消。

#### 试听预约

「试听预约」标签页查看家长留资，可更新状态（待联系/已联系/已到访/已转化/已取消）、填写跟进备注和下次跟进日期。

#### 缴费记录

按缴费单号或学员搜索，展示方式、登记人、时间、金额。

### 3.5 课程与定价

三个标签页：

1. **课程管理**：名称、分类、阶段、适龄、课时、频率、单次时长、封面字/色、简介、教学目标、标签、首页推荐、上架状态、排序。
2. **班型与价格**：按课程维护不同班型的课时包和价格；`unit` 为按期或按次。
3. **内容大纲**：阶段标题、课时范围、说明、是否展示、排序。

下架课程不会在小程序展示；隐藏大纲不会在小程序课程详情展示。

### 3.6 班级与排课

#### 创建班级

填写班级名称、课程、教师、教室、固定星期、开始/结束时间、容量、状态。

#### 维护班级学员

点击班级行的「学员」：

- 查看名单、剩余课时、入班时间
- 从下拉选择学员加入班级
- 容量满时禁止加入
- 可将学员移出班级（不影响报名与课时记录）

#### 新建课次

填写班级、课次序号、日期、起止时间、教师、教室、状态、备注。

后端自动校验：

- 教师同一时间不能上两节课
- 教室同一时间不能重复占用
- 同一班级学员不能在两个班级同一时间上课
- 同班级课次序号不能重复
- 结束时间必须晚于开始时间

冲突时保存失败并提示具体原因。

#### 周课表

「周课表」标签按周一至周日展示课次，可用上一周/下一周切换；点击课次直接编辑。保存时仍会执行教师/教室/学员冲突校验。

#### 课次状态

`SCHEDULED` 待上课、`DONE` 已完成、`CANCELLED` 已取消。点名后自动变 DONE。

### 3.7 点名与消课

1. 进入「点名与消课」。
2. 在「按课次点名」选择日期/状态，找到课次。
3. 点击「去点名」或「修正点名」。
4. 为每位学员选择：出勤 / 请假 / 缺勤。
5. 提交。

规则：

- 出勤、缺勤各消 1 课时。
- 请假按已通过请假的规则：课前 4 小时以上不扣，其他扣 1 课时。
- 未审批请假按扣课处理。
- 重复点名只按差额修正，不重复扣课。
- 每次修正写课时流水，操作人留痕。

### 3.8 请假审批

1. 进入「请假审批」。
2. 筛选待审批。
3. 同意：系统按提交时判定的 `deductHours` 写请假出勤与课时差额。
4. 驳回：必须填写原因，家长端可见。

注意：

- 审批结果不发送微信通知，家长需在小程序请假记录查看。
- 已通过的请假，家长可申请补课；在「请假审批」行点击「安排补课」，选择补课课次并备注，保存后家长端显示“已安排”。
- 已处理请假不能重复审批；同一请假不能重复安排补课。

### 3.9 作品管理

三个标签页：

1. **作品审核**：查看作品、学员、授权状态、审核状态；有授权才可通过展示；已展示可下架。
2. **家长授权**：查看授权范围、方式、日期；可补录授权或撤回授权。
3. **评论审核**：家长留言待审核；通过后展示，可隐藏。

上传作品：

- 点击「上传作品」
- 选择学员、填写标题、书体、内容、上传图片、教师点评
- 勾选「已取得家长授权」
- 提交后状态为 PENDING，需在作品审核中通过

> 未取得 ACTIVE 家长授权的学员不能上传作品，也不能通过审核展示。

### 3.10 机构内容

四个标签页：

1. **机构资料**：名称、品牌、标语、简介、理念、电话、微信、营业时间、地址、经纬度、交通。保存后小程序同步。
2. **教学环境图片**：上传图片、修改说明、删除；首页和机构介绍展示。
3. **师资团队**：新增教师（姓名、手机号必填）、编辑、启用/停用、解绑微信。
4. **资质公示**：新增/编辑/隐藏/删除；已核验且展示的才在小程序显示。
5. **公告管理**：新增、编辑、发布/隐藏、删除。

### 3.11 基础数据

维护：课程分类、课程阶段、班型、教室、请假原因、缴费方式、试听时段。

这些数据是小程序筛选、下拉与表单选项来源，停用后不再出现。

### 3.12 业务规则

可修改：

| 规则键 | 默认 | 说明 |
|--------|------|------|
| `leave_cutoff_hours` | 4 | 课前多少小时以上请假不扣课 |
| `renewal_threshold` | 3 | 剩余课时 ≤ 该值进入续费预警 |
| `validity_months` | 12 | 课时有效期（月） |
| `slot_hold_hours` | 48 | 未缴费报名保留时间（展示口径） |
| `lesson_duration` | 60 | 默认单次时长 |
| `auto_consume` | 1 | 点名出勤自动消课 |
| `comment_enabled` | 1 | 作品留言审核后展示 |
| `makeup_enabled` | 1 | 已通过请假可申请补课 |

### 3.13 用户与权限

仅管理者可进入。四个标签页：

1. **账号列表**：教务、教师、家长账号；可新建教务、编辑、重置密码、启用/停用、解绑微信。教师账号建议在「机构内容 → 师资团队」创建。
2. **角色权限**：管理者/教务/教师/家长四个角色；管理者不可削减；教务可按模块勾选查看/新增/编辑/删除/特殊操作。
3. **家长绑定**：
   - 待审核绑定 / 解绑申请
   - 通过/驳回
   - 新增绑定（一个学员最多 2 位有效监护人）
   - 直接解绑
4. **登录与变更记录**：登录、账号变更、绑定审核等日志。

### 3.14 统计报表

顶部可选择「本月 / 近 6 个月 / 近 12 个月」。

- 核心指标：报名申请、累计消课、本期实收、续费预警
- 报名与试听趋势
- 线下收入构成
- 教师课时统计：带班数、课次、出勤率、请假审批
- 班级课时与出勤
- 续费分析：剩余课时 ≤ 阈值，展示有效期、上次缴费，可直接「登记续费」
- 「导出 CSV」：可用 Excel 打开，包含核心指标、教师、班级、续费名单，不含手机号

登记续费：

1. 点击「登记续费」或右上角按钮。
2. 选择学员、充值课时、实收金额、缴费方式、项目、备注。
3. 确认后立即增加课时、写缴费记录与课时流水。

> 登记续费前必须确认线下款项已到账。

## 四、小程序操作

### 4.1 登录与游客

- 打开小程序进入首页，游客可直接浏览：首页、课程、师资、作品、机构介绍。
- 游客点击课表、课时、报名、请假等需要登录的页面时，会提示登录。
- 登录页提供：
  - 微信一键登录（家长）
  - 教师登录（手机号匹配）
  - 先随便逛逛
- 开发环境有「开发者联调」入口，可用演示数据登录；生产环境自动隐藏。

### 4.2 首页

- 品牌与标语
- 推荐课程
- 师资团队
- 教学环境
- 学员作品
- 机构地址、电话、一键拨号、地图导航
- 登录家长显示「家长服务」：课表、课时、报名记录、请假记录

### 4.3 课程体系与课程详情

- 按分类筛选、搜索课程
- 课程详情展示适龄、课时、频率、阶段、教学目标和分阶段大纲
- 价格按班型展示，到店缴费
- 可预约试听、报名登记、联系教务

### 4.4 试听预约

填写学员姓名、年龄、家长称呼、手机号、意向课程、期望时段、备注，勾选隐私说明后提交。

提交成功页展示预约编号；教务会电话确认，不发送短信/微信通知。

### 4.5 作品墙

- 全部 / 硬笔 / 软笔 / 本月新作
- 作品详情：大图、作者、班级、教师点评、点赞、分享、留言
- 留言需教务审核后展示
- 登录家长可留言；教师账号不能以家长身份留言

### 4.6 我的（家长）

- 切换子女
- 剩余课时、累计上课、待审批请假
- 学员档案、课时账户、上课记录、报名记录、请假记录、成长相册
- 账号与绑定、机构介绍、师资、联系教务
- 退出登录

### 4.7 我的课表

- 切换子女
- 按周切换，按天查看
- 显示课次状态、出勤、请假、本次消课
- 点击课次查看详情
- 开课前可发起请假

### 4.8 请假与补课

1. 课表或课次详情点击「请假」。
2. 选择课次、原因、补充说明。
3. 系统根据开课时间判断是否扣课。
4. 提交后状态「待审批」。
5. 在「请假记录」查看通过/驳回、审批人、扣课判定。
6. 已通过且未安排补课的，可点击「申请补课」，由教务安排。

### 4.9 报名登记

1. 课程详情点击「报名登记」。
2. 选择学员、课程、班级（班级显示剩余名额）。
3. 提交后状态「待确认」。
4. 教务确认后变「待缴费」，到店缴费。
5. 缴费后变「已入班」，课时到账。
6. 未确认/待缴费状态可在报名记录中取消。

### 4.10 课时账户

- 剩余、累计购买、累计消耗、有效期
- 充值、消课、修正流水
- 剩余课时低于阈值显示续费提醒
- 联系教务续费，不支持线上支付

### 4.11 上课记录与成长相册

- 上课记录按出勤/请假/缺勤筛选，展示教师、教室、消课结果
- 成长相册按月展示已授权作品和教师点评

### 4.12 账号与绑定

- 家长身份说明
- 微信绑定状态、手机号脱敏
- 添加已有学员：输入学员编号 + 主监护人手机号后四位
- 新建学员档案：填写孩子信息，提交后等待教务审核
- 申请解绑：进入教务审核
- 教师账号说明：后台创建、按手机号登录、与家长身份互斥

### 4.13 教师工作台

- 今日课程、本周排课
- 待审批请假、待审核作品
- 点名与消课
- 请假审批
- 上传作品
- 退出登录

#### 点名

1. 工作台点击「去点名」。
2. 默认全部出勤，可逐人切换出勤/请假/缺勤。
3. 提交后自动消课。
4. 已点名可再次提交修正，只调差额。

#### 请假审批

1. 进入「请假审批」。
2. 通过或驳回。
3. 驳回必须填写原因。
4. 通过后自动同步家长端记录与课时。

#### 上传作品

1. 选择学员（显示是否已授权）。
2. 上传图片。
3. 填写标题、书体、内容、点评。
4. 勾选家长授权确认。
5. 提交后等待教务审核。

## 五、标准业务流程

### 5.1 新学员入班

1. 家长微信登录 → 添加学员（新建或绑定已有）。
2. 教务在「用户与权限 → 家长绑定」审核通过。
3. 家长在小程序报名 → 选择课程与班级。
4. 教务确认报名。
5. 家长到店缴费。
6. 教务登记缴费 → 课时到账、加入班级。
7. 教务在「班级与排课」确认名单与课次。
8. 教师上课点名。

### 5.2 试听转化

1. 家长提交试听预约。
2. 教务电话联系，更新试听状态与跟进备注。
3. 到店试听。
4. 家长报名 → 进入报名流程。

### 5.3 点名与消课

1. 教师课后点名，或教务在后台点名。
2. 出勤/缺勤自动消 1 课时。
3. 请假按审批规则。
4. 课时流水、家长端课表、上课记录同步。

### 5.4 请假与补课

1. 家长课前提交请假。
2. 系统判定不扣/扣 1 课时。
3. 教师或教务审批。
4. 家长查看结果。
5. 通过后可申请补课。
6. 教务安排补课，不重复计费。

### 5.5 续费

1. 统计报表查看续费预警。
2. 教务电话跟进。
3. 家长到店/转账缴费。
4. 教务在报表中「登记续费」。
5. 课时到账，流水可查。

### 5.6 作品发布

1. 教务在作品管理补录家长授权（或家长线下授权）。
2. 教师上传作品，或教务代上传。
3. 教务审核通过。
4. 作品在小程序作品墙、成长相册展示。
5. 家长可点赞、分享、留言；留言审核后展示。

## 八、常见问题

**Q：家长登录后看不到孩子？**
A：需要先提交绑定申请，并由教务在「用户与权限 → 家长绑定」审核通过。

**Q：教师登录提示未匹配账号？**
A：确认后台教师档案的手机号与登录手机号一致，且教师状态为启用；教师账号由后台创建。

**Q：教师和家长可以是同一个人吗？**
A：可以，但必须使用两个不同的微信号，分别作为教师和家长登录；同一账号不能切换身份。

**Q：为什么报名后没有课时？**
A：报名提交只是「待确认」；需教务确认、到店缴费并登记缴费后才会充值课时。

**Q：为什么点名后余额没有重复减少？**
A：点名是幂等的，重复提交只按差额修正，不会重复扣课。

**Q：请假通过后为什么扣了课时？**
A：请假在开课前不足 4 小时提交，按规则扣 1 课时；具体判定在提交时已固定，并在请假记录展示。

**Q：作品为什么不能通过审核？**
A：作品缺少 ACTIVE 家长授权。请先在「家长授权」补录授权。

**Q：家长能自己解绑吗？**
A：不能立即解绑。家长提交解绑申请后，需教务审核；审核期间仍可查看学员信息。

**Q：支持线上支付吗？**
A：不支持。所有缴费均为线下登记，系统只记账与充值课时。

**Q：会发送短信或微信通知吗？**
A：不会。审批结果、上课与课时变化需家长主动在小程序查看。

## 九、日常维护清单

- 每天：查看待确认报名、今日课程、待审批请假。
- 每周：核对课表、班级容量、续费预警。
- 每月：导出统计报表，核对缴费记录与课时流水。
- 每学期：检查课程价格、内容大纲、教师状态、资质有效期。
- 随时：家长绑定/解绑审核、作品授权与评论审核。
- 定期：数据库与上传文件备份，检查服务器磁盘与日志。
