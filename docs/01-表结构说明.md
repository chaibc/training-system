# 翰墨学堂 · 数据库表结构说明

> 适用版本：MySQL 8.0；字符集 utf8mb4；排序规则 utf8mb4_general_ci。
> 与建表脚本 `sql/schema.sql` 一一对应，共 **38 张表**。
>
> **2026-11-05 变更**：
> 1. `classroom / class_type / course_category / course_stage / leave_reason / payment_method / trial_slot / notice / qualification / institution_image` 共 10 张表新增 `deleted TINYINT NOT NULL DEFAULT 0`，删除改为逻辑删除；
> 2. `qualification.valid_until` 由 `VARCHAR(50)` 改为 `DATE`，空值表示「长期有效」（原本存字符串「长期」的种子数据已改为 `NULL`）。

## 一、设计约定

- 主键统一使用 `BIGINT AUTO_INCREMENT`，业务编号（报名号、缴费单号、请假单号等）单独存放并建唯一索引。
- 金额使用 `DECIMAL(10,2)`，课时使用 `DECIMAL(8,1)`，避免浮点误差。
- **不建立物理外键**，通过应用层与索引保证关联完整性，便于数据迁移、导入与演示环境切换。
- 核心业务表使用 `deleted` 逻辑删除；日志、关系与流水表不做逻辑删除。
- 时间字段使用 `DATETIME` / `DATE` / `TIME`，生产服务器统一设置 `Asia/Shanghai` 时区。
- 家长与学员、家长与作品授权等多对多关系均有唯一索引，防止重复绑定或重复授权。
- 小程序公开内容全部来自数据库：机构资料、课程、价格、大纲、师资、作品、公告、资质。

## 二、业务关系总览

```text
sys_user（管理者/教务/教师/家长）
  ├─ teacher_profile 1:1 教师档案
  ├─ parent_profile  1:1 家长档案
  └─ parent_student  N:N 家长-学员（最多 2 位有效监护人）
student 学员
  ├─ parent_student 绑定家长
  ├─ class_student 加入班级 → class_group → course
  ├─ lesson 课次 → attendance 点名 → hour_ledger 课时流水
  ├─ leave_request 请假 → makeup_arrangement 补课
  ├─ enrollment 报名 → payment_record 缴费 → hour_account 充值
  ├─ work 作品 → work_auth 家长授权 → work_comment 留言
  └─ hour_account 课时账户 1:1 / hour_ledger 流水
course 课程 → course_price 价格 / course_outline 大纲
class_group 班级 → class_student / lesson / class_group.teacher_id
institution_info / institution_image / qualification / notice / business_rule 客户端内容与规则
```

## 六、索引与数据完整性

- `sys_user.username`、`sys_user.wechat_openid`、`student.student_no`、`parent_student(parent_user_id,student_id)`、`class_student(class_id,student_id)`、`attendance(lesson_id,student_id)`、`hour_account.student_id`、`work_auth(student_id,parent_user_id)` 均有唯一约束。
- 报名申请号、缴费单号、请假单号、试听预约号均有唯一索引；生成规则见后端服务。
- 业务查询常用索引：学员状态、班级课程、课次日期、课次教师、请假状态、课时流水时间、缴费时间。
- 逻辑删除由 MyBatis-Plus 自动拼接 `deleted=0`；查询原生 SQL 时需自行加上该条件。

## 七、备份与迁移注意

- 使用 `mysqldump --single-transaction --routines --triggers --default-character-set=utf8mb4` 导出。
- 上传文件目录 `UPLOAD_DIR` 与数据库必须同时备份；只恢复数据库会导致作品/环境图片 404。
- 迁移后核对 `sys_user`、`student`、`hour_account`、`hour_ledger`、`payment_record`、`attendance` 的行数与金额/课时合计。
- 生产环境禁止直接执行 `sql/seed.sql`（演示数据）；使用 `sql/seed-prod.sql` 初始化基础字典与管理员账号。
