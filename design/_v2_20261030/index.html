02 / SCOPE

本期范围与明确排除项

依据本次任务要求，以下两项不进入原型与后续开发范围。
!
不做消息通知：不实现微信订阅消息、站内消息中心、上课提醒、续费提醒推送。家长通过「课表」「请假记录」「报名记录」主动查看状态；机构通过电话 / 到店沟通。
不做线上缴费：不接入微信支付。报名、续费、补费等均由教务在后台登记线下收款，并写入课时账户与缴费流水。小程序端仅展示应缴费用与线下缴费状态。

04 / DEMO

建议演示路径

按真实业务顺序操作，能看到状态在两端之间同步的口径设计。

家长端：从了解课程到请假

  • 1
    首页 → 课程体系 → 课程详情切换硬笔 / 软笔 / 幼小衔接筛选，打开课程对比，查看五阶段大纲。
  • 2
    预约试听 / 报名登记填写表单并提交，进入成功页；报名记录中查看「待确认 → 待缴费 → 已入班」状态与线下缴费说明。
  • 3
    我的课表 → 课次详情 → 请假申请切换子女、按天筛选；提交请假后进入结果页，在请假记录中查看审批状态与补课入口。
  • 4
    作品墙 → 作品详情筛选作品、点赞、打开分享面板、提交留言（审核后展示）。
  • 5
    我的 → 学员档案 / 课时账户查看档案、课时流水、上课记录与成长档案。

管理端：从报名到消课

  • 1
    报名与缴费确认报名 → 状态变「待缴费」→ 登记线下缴费 → 状态变「已入班」，演示线下收款与课时写入。
  • 2
    班级与排课查看冲突提示，点击课次查看详情，发起调课并确认；切换周次查看课表。
  • 3
    点名与消课切换出勤 / 请假 / 缺勤，观察汇总与预计消课变化；提交后生成消课结果；在消课记录中修正。
  • 4
    请假审批同意后计数联动，切换「已通过」查看；已有请假可安排补课。
  • 5
    作品管理尝试通过未授权作品（会被拦截），补录授权后再通过；体验评论审核。统计报表中查看图表数据表。

06 / FILE

文件与说明

所有原型均为纯 HTML / CSS / JavaScript，无外部依赖，双击即可在浏览器打开。

文件结构

  • A
    index.html设计总览与范围说明（当前页）
  • B
    miniprogram.html小程序端 24 个功能页 + 3 个流程结果页，左侧目录可直达任意页面
  • C
    admin.html管理后台 11 个功能页，侧边栏切换，含学员抽屉、弹窗、图表与审批交互
  • D
    _v1/旧版静态设计稿备份（含已排除的通知与线上缴费内容，请勿作为交付依据）

原型约定

· 所有数据为演示样例，不代表真实机构经营数据；
· 手机号、身份证等敏感信息均按脱敏展示；
· 报名、续费、补费等金额仅用于流程演示；
· 未接入后端、微信登录、支付接口与地图接口，相关按钮以弹层 / 提示说明真实调用；
· 通知与线上缴费为本次明确排除项，页面中仅保留说明性文字，不提供入口。
